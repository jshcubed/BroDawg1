This is an example note. Each file in `notes/` is one note.

To add a new note:
1. Copy `TEMPLATE.md` into `notes/` with a name like `2026-06-30-my-topic.md`.
2. Fill in the title, date, and a few tags.
3. Write whatever you want below the frontmatter.

To find something later, just ask Claude things like:
- "What notes do I have tagged #idea?"
- "Did I write anything about my car insurance renewal?"
- "Summarize my notes from this week."

Delete this file whenever you like — it's just a demo.
