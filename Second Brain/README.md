# 🧠 Second Brain

A personal knowledge base for capturing, organizing, and connecting ideas, notes, and learnings.

This Second Brain follows a lightweight, markdown-first approach. Every note is a plain `.md` file so it stays portable, searchable, and version-controlled.

## 📂 Structure

```
Second Brain/
├── README.md              # You are here
├── note-template.md       # Copy this to start a new note
└── notes/                 # All your notes live here
    └── welcome.md         # Example note
```

## 🚀 How to Use

1. **Create a note** — copy `note-template.md` into `notes/` and rename it (e.g. `notes/my-new-idea.md`).
2. **Fill in the front matter** — title, date, tags, and status help you find things later.
3. **Write freely** — capture the idea first, polish later.
4. **Link notes together** — reference other notes with `[[note-name]]` or relative markdown links so ideas connect.
5. **Tag consistently** — use a small, reusable set of tags to group related notes.

## 🏷️ Suggested Tags

- `#idea` — raw thoughts and sparks
- `#project` — anything tied to active work
- `#reference` — facts, snippets, and resources to keep
- `#todo` — actionable items
- `#learning` — things you're studying

## 🗂️ Organizing Principles

- **Capture everything, organize later.** Don't let perfect structure block you from writing.
- **One idea per note.** Small, atomic notes are easier to link and reuse.
- **Review regularly.** Revisit notes, refine them, and prune what's stale.
